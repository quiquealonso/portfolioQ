Proyectos

Seis proyectos: dos apps móviles conectadas a Supabase, una plataforma de pedidos con Spring Boot, gestión empresarial con Odoo, una aplicación de escritorio en Java y la web que estás viendo.

01 — Móvil · Angular + Supabase

Stockly

Control de stock para restaurantes y empresas de eventos, pensado para usarlo con una mano: botones −/+ grandes, filtro de productos bajo mínimos, pedidos favoritos que se suman al stock de una vez y eventos que descuentan el consumo en un solo paso. Si dos personas tocan el mismo producto a la vez, no se pisan.

Qué hace
Stock, proveedores, pedidos favoritos, eventos e historial de cada movimiento
Tecnología
Angular 22 con signals, Supabase (PostgreSQL y Auth) y Capacitor para la app de Android
Sin backend
Seguridad en la base de datos: RLS para el personal, funciones atómicas y un trigger que guarda el historial
Extra
Demo con datos ficticios y vídeo grabado automáticamente con Playwright

02 — Móvil y escritorio · Angular + Supabase

Gestor Campos

Las cuentas de cada campo agrícola por campaña: gastos, cheques de la cosecha, beneficio por hanegada y lo que aún queda por pagar. Un gasto común se reparte entre todos los campos según su tamaño, cuadrando al céntimo, y las estadísticas comparan un año con otro.

Qué hace
Campos, pagos, ingresos, pagos conjuntos y estadísticas por año y entre años
Tecnología
Angular 20 y PrimeNG, Supabase, Capacitor para Android y Electron para Windows
Sin backend
RLS por propietario, funciones SQL en una sola transacción y validación con restricciones CHECK
Extra
Demo con datos ficticios y vídeo grabado automáticamente con Playwright

03 — Web · Angular + Spring Boot

PanGestión

Plataforma de pedidos y gestión para panaderías, bares y restaurantes. Cada negocio tiene su propio panel, y sus clientes piden desde una web pública pensada para el móvil y para cualquier edad: un asistente de cinco pasos con botones grandes que termina con el número de pedido. En el obrador, la tabla de producción del día se actualiza sola.

Panel
Pedidos por día y estado, producción por franja horaria, catálogo con alérgenos, clientes y usuarios con roles
Web pública
Negocio, productos, quitar ingredientes, datos y hora de recogida, sin necesidad de cuenta
Backend
Java 21, Spring Boot 4, Spring Data JPA con Hibernate y Spring Security con JWT
Datos
H2 en desarrollo o PostgreSQL con Docker Compose
